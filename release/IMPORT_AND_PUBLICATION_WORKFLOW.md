# Import and publication workflow

Target repository:

`mabojviu/nonhomogeneous-relational-time`

Recommended initial release:

`v0.1.0 — Article 3 pre-synthesis scientific freeze`

The repository is deliberately separate from the Article 2 repository.

Workflow:

1. Populate the public repository with the curated scientific tree.
2. Preserve the exact binary freeze and source-package SHA-256 values.
3. Reserve a Zenodo record and obtain the DOI.
4. Bind the DOI into `CITATION.cff` and `RELEASE_STATUS.md`.
5. Tag the DOI-bound tree as `v0.1.0`.
6. Publish the exact frozen archive to Zenodo.
7. Preserve this tag when the Article 3 manuscript is later added.
